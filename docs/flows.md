# PasarDesa Flows

## Super admin
1. Login with credentials.
2. Create tenant and initial BUMDes admin.
3. Share the generated temporary password.

## BUMDes admin
1. Login and complete tenant contact details.
2. Create seller accounts.
3. Review all orders inside the tenant.
4. Approve or reject payment proofs when needed.

## Seller
1. Login with temporary password.
2. Update contact and WhatsApp number.
3. Configure payment methods.
4. Create products and monitor only their own orders.

## Buyer
1. Visit `/pasar/[tenantSlug]`.
2. Add products from multiple sellers within the same tenant.
3. Checkout as guest.
4. Receive split seller orders, payment instructions, and WhatsApp actions.
5. Upload proof for transfer or QRIS per seller order.
